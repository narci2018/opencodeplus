# Floating Chat Button Icons

Place icon files in this directory. Supported formats: SVG, GIF, PNG, JPEG, WebP.

To add a new icon:
1. Put the file in this directory (e.g., `robot.gif`)
2. Register it in `ICON_OPTIONS` in `iCubeFloatingChatMainService.ts`
3. Add it to the settings UI in `FloatingChatButtonIcon.tsx`
